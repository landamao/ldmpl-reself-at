# 补回艾特自身

> 顾名思义，补回艾特自身

## 为什么需要

AstrBot在处理消息时，会把Bot自身的艾特去掉。

如果用户同时艾特了Bot和别人，比如：

```text
@咪咪 @松坂砂糖 睡了吗
```

LLM实际看到的只有：

```text
@松坂砂糖 睡了吗
```

这样LLM**完全不知道自己也被艾特了**，可能会产生困惑或**吃醋**。

本插件会在消息进入LLM请求队列时，把被去掉的自身艾特补回去，让LLM看到完整上下文。

## 效果

启用前：

```text
@松坂砂糖(231224) 睡了吗
```

启用后：

```text
@咪咪(myself) @松坂砂糖(231224) 睡了吗
```

这样LLM就能知道**自己也被艾特了**。

## 说明

- 无命令，无配置，即装即用。
- 只影响LLM请求文本，不影响真实消息发送。
- 如果定位失败，不会修改原文本。
- 仓库：[https://github.com/landamao/ldmpl-reself-at](https://github.com/landamao/ldmpl-reself-at)
